# Notebooks

`reference/19_hotel_cancellations.ipynb` is the unchanged supplied teaching notebook.

`hotel_cancellations.ipynb` is the thin client for loading, features, training, scoring and the given overbooking policy. Calculations live in `src/hotel_cancel/`. Select the project environment. The executed copy is ignored at `artifacts/hotel_cancellations.executed.ipynb`.

If the documented Mac editable-install issue recurs, run `.venv/bin/python scripts/repair_local_import.py` from the repository root, then restart the notebook kernel. No PYTHONPATH override is required.
